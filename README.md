An entry for the make.fun bounty [The Router Confesses](https://make.fun/competitions/u-carbon-forge-the-router-confesses-f98f6b9e).

## The entry

A home Wi-Fi router excuses itself for dropping the connection at the
exact climax of a movie — one line, in the router's own smug little
voice, with a secret it has been keeping since episode two.

## How it works

`main.py` writes the single entry line to `/output/entry.txt`
(1–200 UTF-8 characters, validated before writing).

```sh
python3 main.py
```
